# Rami Hanna Portfolio

Personal portfolio for my robotics, software, sensing, simulation, and product projects.

Live site: https://www.rami-hanna.com/

## Purpose

The site presents a coherent public story around my work:

- robotics software
- controls and sensing
- simulation and applied research
- computer-vision and data workflows
- product-minded software projects around real-world systems

## Featured Projects

- **PerPlant**: public-safe summary of ROS2 thermal/GPS sensing and CV dataset workflow work.
- **Thesis**: soft-finger actuation modeling and benchtop validation.
- **SunnySips**: iOS + FastAPI outdoor recommendation project using weather, sun geometry, and maps.
- **TRYBE**: mobile/product architecture for real-world session participation.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Responsive image-heavy project pages
